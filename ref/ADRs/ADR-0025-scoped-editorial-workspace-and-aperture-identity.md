# ADR-0025: Scoped editorial workspace and Sculpted aperture identity

- Status: Accepted; shared foundation and central forms implemented, remaining overview/topic/branding migration and acceptance tracked in [bundle 04](../work/04-main-workspace-design/main-workspace-design.spec.md).
- Date: 2026-10-07
- Scope: central contextual header/content and replacement artwork in existing brand slots/native icons. Amends only ADR-0007/0013's generic central composition, heading/primary-action conventions and brand artwork.

## Context

The user selected [Quiet action groups](../../docs/design/component-designs/02-project-overview/project-overview-selection.md) for present/future central pages and subsequently selected the [Sculpted aperture](../../docs/design/component-designs/03-learning-studio-logo/learning-studio-logo-selection.md) identity. The generated references establish direction, not implemented behavior or native evidence. Global heading/button changes would affect excluded panels and the separately approved AI workbench.

## Decision

Adopt subject/task-first editorial headings, readable context/document sections, faint static lilac illumination, opaque neutral gradient surfaces and quiet labelled independent commands. Maintain the existing semantic Light/Dark palette and local Appearance preference. Scope additional tokens/selectors to the explicit central content root and contextual header, never the whole workspace ancestor containing the AI dock. Shared renderer primitives own presentation only; features retain authoritative state, drafts, callbacks and typed capabilities. The canonical [main-workspace standard](../patterns-main-workspace.md) records tokens, consumers, complete states and future-feature evidence.

Adopt exactly three separate broad page shapes forming the selected upright triangular aperture: two rising sides and a shallow broad bottom, with three separation gaps. The large selected mark/final reference governs rather than the sheet's rounder miniature. One editable vector construction will supply glyph-only in-app Light/Dark/monochrome artwork and reproducible ICO/ICNS/PNG native exports. Production glyph fill is flat; native tiles may use restrained lilac on charcoal. Preserve Learning Studio text, existing slot dimensions, accessible names and behavior. This artwork replacement is the sole side-panel exception. Asset paths, export commands, small-size review and native package evidence must be documented when implemented.

Preserve rail/sidebar/drawer/account/Settings/detail panels, editor/confirmation dialog structures, integrated title strip/native menus/controls and the ADR-0022 dock. Do not change app identity/profile paths, window transparency, IPC/security, inference producers, saved schemas or topic/file ownership. Ordinary reading starts no inference and does not imply mastery. Topic destinations must integrate the existing ADR-0023 navigation owner when implemented.

## Consequences and migration evidence

Central pages can share a consistent vocabulary without imposing it on other regions. Opaque gradients provide the selected glass appearance without backdrop filters, native transparency or a platform dependency. New central features document states, navigation/restoration/AI effects and actual Light/Dark, narrow/zoom/focus/contrast/flow evidence.

The initial foundation covers dashboard, setup/refinement, loading, messages and project/model recovery. Overview/topic adoption, logo/vector/export consumers, complete integrated flow acceptance and native qualifications are separate work in bundle 04. Accepting this decision does not certify remaining screens, accessibility, live providers, native windows or app icons. ADR-0013 preference/security, ADR-0019 locality/recovery, ADR-0020 flow ownership, ADR-0021 commit discipline and ADR-0022/0023/0024 remain otherwise unchanged.
