# ADR-0026: Illustrated topic content and OpenRouter media

- Status: Accepted; contract/port foundation, main storage/OpenRouter accounting adapters and fixed-image utility implemented; chapter/replacement runtime and reader integration pending in [bundle 05](../work/05-illustrated-topic-content/illustrated-topic-content.spec.md).
- Date: 2026-10-07
- Scope: explicit selected-topic chapters and image replacement, binary media publication, independent ordinary OpenRouter credentials and durable call accounting. Extends only ADR-0019's text-only authoring/outline commit marker and ADR-0022's sanctioned profiles, transport and public projections.

## Context

The learner requested authored illustrated chapters, independent image-provider configuration and cost history, and editable-prompt image replacement. Existing topic plans are not chapters. The outline transaction's commit marker cannot publish chapter-only binary revisions safely. A buffered image result requires a separate liveness policy and cannot fit into public AI frames. Provider charges remain relevant even if an image is discarded or fails to save.

## Decision

Keep chapter text on the selected project's existing sanctioned ChatGPT/Pi transport. Use an app-owned Pi-compatible image adapter with an explicit ordinary OpenRouter key, the dedicated image route and exactly GPT Image 2 (`openai/gpt-image-2`), Seedream 5 Pro (`bytedance-seed/seedream-5-0-pro`) and Nano Banana 2 (`google/gemini-3.1-flash-image`). Main fixes endpoints under `https://openrouter.ai/api/v1`; provider metadata cannot redirect routing. Validate supported settings per selected endpoint; optional resolution/format/quality are absent when unsupported. No environment credentials, automatic retries, fallback models, reference-image input, OpenRouter text or speech are authorized.

Main resolves registry project handles to portable project/topic identity. Core owns chapter behavior/coverage/recovery and narrow ports; shared owns strict serializable contracts. Main owns privileged storage, provider settings, ledger, sender authorization and worker lifecycle. Renderer and preload retain named capabilities only. Chapter starts claim the shared coordinator synchronously; initial starts allocate chapter IDs locally, while continuation requests include the known chapter/run IDs before asynchronous authority resolution. Child image calls share the chapter lease; standalone replacement claims its own. All profiles use the existing workbench, cancellation and awaited worker-exit rules.

Validated plans preserve the exact saved objectives with zero-based objective indices, stable section/image IDs and complete coverage. Explicit activations allow at most 48 text turns, 24 sections and six planned images; one image request produces one result. Persist lifetime counters separately from per-activation counters. Checkpoints include slot-level call IDs and unresolved dispatched states: restart/ordinary Continue never automatically repeats a paid call with an unknown outcome. Explicit retry must explain that uncertainty. A budget pause owns no active lease after actual cleanup.

Publish immutable owned output beneath `<topic-folder>/content/<chapter-id>/<revision-id>/`; use a versioned `.edu/chapters/<encoded-topic-id>.json` manifest as an independent commit marker and a separate content-publication journal. Portable checkpoints live in `.edu/content-runs`. Apply ADR-0019 exclusive-folder/link/root/baseline checks and serialize all project mutations. Recheck topic, learning context, inspected sources and manifest before publication. Preserve unknown external versions/journals; never roll them back or infer content from filenames. `.edu/project.json`, sources and unrelated topics do not change. Reading unknown/corrupt content does not perform migration writes. Missing assets degrade reading while retaining prose. Generated output cannot become a primary citation recursively.

An initial complete chapter publishes after independent acceptance; partial text remains checkpointed. Fully valid prose with incomplete illustrations may publish as `needs-images`; deliberate text-only output is labelled `text-only`. Regeneration retains the old published revision until a replacement is publishable. Individual image candidates have a new revision identity and bind the expected current revision/image version/manifest digest. Only explicit acceptance publishes them. Retain originals and storage-only retry state; discarded results retain call cost history. Retained revision pointers are bounded projections, not authorization to silently delete historical assets or truncate their ancestry.

Accept only PNG/JPEG/WebP after actual off-main decoding and independent main acceptance of ownership, bytes, dimensions, MIME and digest: 16 MiB/16 megapixels per image, 64 MiB current-chapter media and 32 MiB encoded response. Media transfer uses a private worker channel or app-assigned staging handle; the public 96 KiB AI frame/64 KiB preview caps do not change. Media requests wait at most 300 seconds initially, then 60 seconds without response bytes, with no total receiving deadline within byte bounds. Worker health stays independent. Require a valid accepted result and clean EOF; no fabricated streaming/percentage. Main serves only authorized opaque project/chapter/image/version identities with raster sniffing, restrictive CSP and link/traversal rejection. Markdown is inert, with no raw HTML/script execution or remote image retrieval.

OpenRouter settings/credentials, cache and opaque connection epochs belong in the profile separately from ChatGPT. Reuse protected storage and disclosed local fallback; validate a proposed key through a non-inference request before replacing the working key. Renderer never receives the key or a substring. Removal preserves content/history. Active provider inference blocks key/model changes. Metadata reads do not claim inference; use bounded single-flight refresh, 30-second timeout, 2 MiB responses and 24-hour cache freshness, without polling or paid startup calls.

Main persists an immutable intent before every app OpenRouter HTTP dispatch, including non-inference requests, then appends terminal/reconciliation transitions. Storage failure before intent denies dispatch; terminal failure leaves the intent unresolved without replay authorization. Store only safe endpoint classes/purposes/IDs/context labels/status and estimate/reported-cost projections, never full URLs, keys, prompts, payloads, raw errors or absolute paths. Editable prompts belong only in chapter metadata. Use exact nonnegative decimal-string USD values with up to 18 fractional digits; unknown cost is distinct from zero. Count each call's latest reported cost once, separately from publication disposition and separately from provider-wide key usage. Reconcile only a known validated generation ID when supported; no management-key history import or aggregate-delta inference. Pricing preserves billable unit/variant and compatible endpoint settings; estimates/ranges/unknowns are labelled and timestamped rather than guaranteed caps.

## Consequences

Chapters, checkpoints, candidate review, ephemeral AI presentation and the profile call ledger have independent ownership. The main storage adapter implements independent publication, checkpoints, candidate records and scoped media resolution behind the workspace mutation queue. The OpenRouter adapter implements independent protected credentials, epoch-bound metadata caching, fixed-route audited metadata requests, exact accounting and paid-request authorization hooks. The fixed-image utility now implements the Pi image route, full Sharp decoding, private correlated authority/accounting/asset acknowledgements and actual-exit plus pending-write settlement. These adapters are not exposed through runtime IPC yet. Later tickets must prove integrated chapter/replacement publication/recovery, global admission, safe serving and reader/settings interactions. Fixture/code acceptance is separate from explicitly authorized live paid qualification, pedagogical review, packaged-worker and native/accessibility evidence. Socratic execution, mastery, speech and web research remain outside this decision.
