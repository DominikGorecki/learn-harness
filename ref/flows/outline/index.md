# Outline generation and cancellation

Review explicit generation, readable saved outlines, topic disclosure, theme switching or cancellation.

[Test implementation](../../../tests/desktop/outline.spec.ts) · [Flow patterns](../../patterns-flow.md)

## Starting conditions

A temporary empty project and the signed local provider fixture returning the sample Bayesian reasoning outline. Pi runs in the actual Electron utility process.

## Journey and assertions

1. Enter a topic, follow connection recovery and verify authorization alone does not start inference.
2. Select the fixture model and verify accepted admission focuses the dock. Select actual partial prose, scroll backwards while it grows, switch Light/Dark and reduced motion, and check current activity/draft/control reachability at minimum-window 200% zoom. The visible draft label remains provisional; no completed-looking result saves before clean EOF. Complete the body and verify the saved outline and selected-model request; capture its editorial overview with independent reading/editing commands.
3. Expand the retained Preview topic plan disclosure for the first topic, assert the module heading and capture its content.
4. Change appearance and verify reading position and persisted outline remain unchanged without another request.
5. Request replacement, decline once, then start a held request and cancel by keyboard; verify terminal Dismiss focus, dismissal back to setup, draft/prior-outline preservation and worker exit.
6. Restart and reopen the saved outline without inference.
