# Project lifecycle and navigation

Review folder selection, learning goals, per-project models, recent projects, navigation or folder relinking.

[Test implementation](../../../tests/desktop/projects.spec.ts) · [Flow patterns](../../patterns-flow.md)

## Starting conditions

Two temporary folders, Bayesian reasoning and Urban ecology, a temporary profile and the local provider fixture. Native folder selection is stubbed to return those owned paths.

## Journey and assertions

1. Capture the empty dashboard, open the first folder and verify that opening alone writes nothing or authorizes no account.
2. Check oversized goal validation, save a valid goal, connect the fixture account and save a model preference.
3. Switch projects and return; verify drafts and model choices belong to their project, including cancellation of the folder dialog; capture the workspace.
4. Exercise the 600-pixel navigation drawer, focus restoration, 200% zoom, overflow and reduced motion; capture narrow and zoomed composer states.
5. Restart and verify saved goal/model state; move the owned folder, discover missing-folder recovery and relink while preserving project identity.

## Run and refresh

```powershell
npm run test:desktop -- tests/desktop/projects.spec.ts --grep "@projects( |$)"
```

The flow ID is also a test tag (`@projects`); use `--grep "@projects( |$)"` to select it exactly when names overlap. Passing runs replace only this flow's platform set and regenerate the table below. Failed/skipped/interrupted runs keep the previous references; inspect their age before relying on them. See the [maintenance workflow](../../patterns-flow.md#creating-or-changing-a-flow).

## Evidence limits

Folder-dialog responses are deterministic stubs, not native chooser interaction. Tests verify real project files and app/profile state. Sample absolute paths are masked in captures when visible. The zoomed checkpoint is scrolled to the save-goal control, so it shows that control and surrounding disclosure rather than the entire composer.

Captures show Electron renderer content, without native title bars/menus. Any visible temporary absolute project paths are masked. Fixture account labels and learning text are synthetic. Visual references supplement the assertions and do not establish learning mastery or live-account access.
