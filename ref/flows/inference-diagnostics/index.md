# Inference diagnostic correlation

Review model/utility transport summaries, log correlation or learner-content exclusions.

[Test implementation](../../../tests/desktop/logging.spec.ts) · [Flow patterns](../../patterns-flow.md)

## Starting conditions

A temporary project/profile, private sentinel content and a local provider fixture. This is a nonvisual flow.

## Journey and assertions

1. Connect the fixture account and run the explicit model diagnostic.
2. Generate through the real Pi utility process using sentinel learning content.
3. Close the app and inspect structured development records for model/utility transport evidence and IPC request correlation.
4. Verify logs exclude learner content, credentials and raw provider/private values.

## Run and refresh

```powershell
npm run test:desktop -- tests/desktop/logging.spec.ts --grep "@inference-diagnostics( |$)"
```

The flow ID is also a test tag (`@inference-diagnostics`); use `--grep "@inference-diagnostics( |$)"` to select it exactly when names overlap. Read the linked test for the exact asserted event fields. Reference output contains run metadata only, not raw log text or diagnostic payloads.
