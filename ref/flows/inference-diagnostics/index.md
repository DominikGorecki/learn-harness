# Inference diagnostic correlation

Review model/utility transport summaries, log correlation or learner-content exclusions.

[Test implementation](../../../tests/desktop/logging.spec.ts) · [Flow patterns](../../patterns-flow.md)

## Starting conditions

A temporary project/profile, private sentinel content and a local provider fixture. This is a nonvisual flow.

## Journey and assertions

1. Connect the fixture account and run the explicit model diagnostic through the real tool-free Pi utility process. Wait for the authoritative verified dock outcome before reopening account settings to inspect the badge.
2. Generate through the real Pi utility process using sentinel learning content.
3. Hold an educational response open through two worker health reports, reject both named model checks with BUSY and no extra request or saved-byte change, cancel it, and verify the owned process exits with the saved project unchanged.
4. Kill a second held worker and verify safe recovery with the saved project unchanged and no owned worker remaining.
5. Close the app and inspect structured development records for byte/transport summaries, health, cancellation, worker loss and IPC request correlation.
6. Verify logs exclude learner content, credentials and raw provider/private values.
