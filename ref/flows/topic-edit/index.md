# Scoped topic rewriting

Review topic editor ownership, topic drafts, local file publication, cancellation or preservation of other topics.

[Test implementation](../../../tests/desktop/topic-edit.spec.ts) · [Flow patterns](../../patterns-flow.md)

## Starting conditions

A temporary sample outline, an owned topic folder with notes, a separate other-topic folder, and a local provider fixture staging reads/edits.

## Journey and assertions

1. Open the independent labelled Edit topic command by keyboard, enter a request and capture Light mode; verify focus restoration and separate other-topic/whole-path drafts through the new quiet command groups.
2. Check oversized input and account recovery; allow project-wide reads but stage writes only to the target topic.
3. Accepted admission closes the editor and focuses the dock under the trusted saved topic title. Observe a held structured topic preview with only the selected stable lesson, visible provisional label and restrained active-topic marker, then cancel; verify neither prior outline nor topic files changed.
4. Return to the retained draft in Dark mode, capture it and capture the reachable rewrite action at 200% zoom.
5. Submit a fixture proposal containing unrelated changes; verify only the selected topic and its owned files/topic mirror are published, with unrelated outline/file state preserved. Assert completed actual reads and exclude raw tool IDs, credentials and read contents from public activity.
6. Verify the successful draft clears and the other-topic draft remains. Start another held request with a long saved topic title/request at narrow 200% zoom; verify reachable current activity, draft and Cancel without horizontal overflow. Cancel while focus and scroll belong to saved reading and verify neither is stolen; restart reopens the saved topic.

## Evidence limits

The file assertions establish scoped publication, not just a visual rename. Live semantic quality and all path-conflict variants require separate evidence.

Captures show Electron renderer content, without native title bars/menus. Any visible temporary absolute project paths are masked. Fixture account labels and learning text are synthetic. Visual references supplement the assertions and do not establish learning mastery or live-account access.
