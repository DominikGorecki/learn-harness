# Explicit chapter illustration recovery

Review text-only chapter completion and explicit retry of failed or uncertain image requests through the typed Electron bridge.

[Test implementation](../../../tests/desktop/topic-content.spec.ts) · [Flow patterns](../../patterns-flow.md)

## Starting conditions

An isolated development Electron profile, a saved topic, deterministic text/image HTTP fixtures and an ordinary synthetic OpenRouter key. No paid live request is used.

## Journey and assertions

Five text requests publish valid text-only prose with zero image calls. Complete Illustrations without a provider returns UNAVAILABLE and creates no progress. After disconnecting ChatGPT and validating the synthetic OpenRouter key, illustration completion makes no new text request.

The first image returns HTTP 402 and the second succeeds. Progress pauses with the first slot unresolved; ordinary Continue makes zero repeated image requests. Explicit retry without uncertain-charge acknowledgement returns CONFLICT. Acknowledged retry makes exactly one new image request, retains `previousAttempts`, publishes the illustrated revision and preserves the original prose/revision. There are three image requests total and still only five text requests.
