# Whole-path outline rewriting

Review numbered outline requests, editor drafts, cancellation, whole-path replacement or restart persistence.

[Test implementation](../../../tests/desktop/outline-edit.spec.ts) · [Flow patterns](../../patterns-flow.md)

## Starting conditions

A real sample .edu document saved in a temporary project, plus a local provider fixture. The request asks to reorder topics and add practical examples.

## Journey and assertions

1. Open the whole-path editor with keyboard navigation; verify focus, enter a numbered request and capture Light mode.
2. Dismiss/reopen, check draft retention and oversized-input validation, then follow account recovery without losing the draft.
3. Select a model, switch to Dark and capture the retained request; verify the dialog and submit action at 200% zoom using native Electron capture.
4. Verify IME composition does not submit; accepted admission closes the editor and focuses the dock once. Observe correlated structured activity and cancel while preserving the prior outline and draft.
5. Submit a fixture revision and verify ordered topics, saved state, model/context transmission, preserved learning goal and cleared successful draft.
6. Let an explicit diagnostic win main admission immediately before the editor submits; verify the rejected editor retains its input/error and makes no competing provider request. Dismiss the editor while its trigger is disabled and verify useful dock-heading focus. Cancel the diagnostic, reopen the preserved draft and verify ordinary trigger focus restoration, then restart and reopen the revised outline.

## Evidence limits

Assertions establish real persistence and Pi context handling using local fixture responses. Captures illustrate editor states, not all recovery branches.

Captures show Electron renderer content, without native title bars/menus. Any visible temporary absolute project paths are masked. Fixture account labels and learning text are synthetic. Visual references supplement the assertions and do not establish learning mastery or live-account access.
