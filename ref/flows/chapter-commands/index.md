[Test implementation](../../../tests/desktop/chapter-reader.spec.ts) · [Flow patterns](../../patterns-flow.md)

An isolated saved topic uses real Electron/preload/main authoring with a local signed ChatGPT protocol fixture and ordinary-key OpenRouter HTTP fixture. Initial cached quote reads produce no HTTP. Settings entry selects OpenRouter even after Appearance was remembered and restores its actual trigger.

Deliberate text-only generation performs five fixture authoring calls. An injected actual manifest marker failure preserves the accepted result; Retry save publishes without inference and updates historical workbench presentation from domain evidence. After ChatGPT sign-out, Complete images uses the saved prose and fixed image provider. A failed image produces explicit uncertain-charge recovery; ordinary Continue sends no duplicate image, and an acknowledged slot retry produces one new request. Two distinct native educational diagrams publish. Regeneration requires confirmation, preserves the current chapter during cancellation, and routes recovery to the owning topic. Explicit text-only replacement changes the chapter while preserving outline and source bytes.
